# HW05 — Request-Response / NuSMV

## Файлы
- `request_response.smv` — модель и шесть CTL-спецификаций.
- `report.md` — отчёт с описанием модели, формулами, ожидаемыми результатами и анализом контрпримера.
- `nusmv_output.txt` — вывод NuSMV при проверке request_response.smv.

## Запуск
Установить NuSMV или совместимый nuXmv, затем выполнить:

```bash
NuSMV request_response.smv
```
